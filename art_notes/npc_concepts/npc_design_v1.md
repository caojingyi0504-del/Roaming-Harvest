# 第一章新增 NPC 设计 v1

## 年轻旅人：诺亚（红狐）

- **职能**：旅人换种会的引导者；第 4 关首通后在房车附近停靠。
- **性格**：好奇、爽朗、爱收集各地的种子故事；说话轻快但不吵闹。
- **造型锚点**：红狐、苔绿短斗篷、奶油衬衣、肉桂色短裤、珊瑚色种子挎包、地图与玻璃种子瓶。
- **交互流程**：初次对话说明“料理换种” → 提供一次固定换种教学 → 后续按刷新周期提供委托与区域种子。
- **建模规范**：拟人低多边形动物；大头、短躯干、圆润四肢、三角切面毛发；哑光暖色材质，不使用写实毛发或高饱和颜色。

## 筛种渔夫：奥提（水獭）

- **职能**：溪流筛种的引导者；第 1 关首通后在池塘边常驻。
- **性格**：耐心、安静、擅长辨认水里漂来的种荚；以生活经验讲解规则。
- **造型锚点**：水獭、雾蓝渔夫帽、燕麦色衬衣、鼠尾草绿围裙、木制圆筛、藤编鱼篓与种子罐。
- **交互流程**：初次对话引导至筛网 → 演示种荚与杂物 → 完成一次保底教学局 → 后续提供每日筛种与累计里程碑提示。
- **建模规范**：拟人低多边形动物；体态略宽、尾巴清晰、双手与筛网动作优先；材质保持纸黏土般柔和，不做油亮水渍。

## 与主角统一的视觉规则

1. 低多边形切面保持可见，但轮廓圆润、面部简洁。
2. 使用米白、鼠尾草绿、暖棕、低饱和珊瑚等奶油童话配色。
3. 角色重要功能由道具轮廓传达：旅人靠种子挎包，渔夫靠圆筛与藤篓。
4. 第一版只制作待机、呼吸、挥手/指引等基础动画；玩法界面由 Godot UI 承担。

## 工程交付顺序

1. 依设定图制作两个 Blender 低模、材质和基础骨骼，导出 `.glb`。
2. 添加 Godot NPC 场景、碰撞/交互范围与高亮。
3. 接入奥提的溪流筛种对话、教学任务与地图提示。
4. 接入诺亚的旅人换种对话、委托刷新与种子兑换入口。
5. 在实际草地、池塘和房车光照中检查比例、色彩、站位与可读性。
