# 服装四视图交接

`player_master_turnaround.png` 是从当前游戏角色优化模型直接渲染的比例母版；同目录的 `player_master/front.png`、`left.png`、`right.png`、`back.png` 是四张独立视图。生成新服装时必须保持母版的物种、头身比、脸型、耳朵、手脚、尾巴长度、站姿、画幅占比和四个视角不变，只更换服装。

通用要求：2×2 四视图，顺序为正面、左侧、右侧、背面；同一中立站姿和比例；全身完整；低多边形奶油童话风；低饱和、哑光、柔和光照；背景干净；无文字、无手持道具、无场景、无高反光、无额外肢体。生成完成后另行导出四张独立 PNG。

## 橄榄园丁服

基于角色母版，仅将服装替换为橄榄绿短斗篷、米白耐磨园艺围裙、旧铜扣、低帮棕色工作靴和一个贴身小种子袋。轮廓紧凑，围裙不遮住尾巴，带少量手工缝补，颜色以低饱和橄榄绿、燕麦米白和旧木棕为主。不要草帽、农具、鲜艳绿色或现代运动服。

目标文件：`olive_gardener_turnaround.png`，模型：`player_olive_gardener.glb`。

## GLB 返回要求

- 每套一个完整角色 GLB，不拆帽子、上衣和下装。
- Y 轴向上，脚底位于原点，正面与母版一致，身高与母版一致。
- 单套不超过约 30,000 个三角面；基础色贴图不超过 1024×1024。
- 删除灯光、相机、隐藏网格和未使用材质；金属度为 0，粗糙度建议 0.75–0.95。
- 将四个 GLB 放入 `assets/wardrobe/models/`，文件名必须与上文完全一致。
